The setup items and drivers of the SQL Server objects (databases, packages, tables, procedures, functions, views, transformers) and the contract of the SQL Server setup aspect. Its implementation is CK.SqlServer.Setup.Engine.

Main types: `ISqlSetupAspect`, `ISqlManager`, `SqlDatabaseItem`, `SqlPackageBaseItem`, `SqlTableItem`, `SqlProcedureItem`, `SqlTransformerItem`.
