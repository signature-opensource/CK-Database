The model of the SQL Server databases of a CKomposable application: the base real objects (`SqlDatabase`, `SqlPackage`, `SqlTable`) and the attributes (`SqlTableAttribute`, `SqlProcedureAttribute`...) that declare their setup and their SQL objects.

`SqlServerAspect` is the "SqlServer" builder aspect that configures the databases, and `SqlDefaultDatabase` is the default database ("db") at run time.
